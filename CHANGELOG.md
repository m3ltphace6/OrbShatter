# Changelog

## 1.0
- Orbs can attack barrels, crates, cracks and breakable walls.
- Priority: living enemies in line of sight, then other destructibles, then containers.
- Settings file Documents\Dungeon Siege LOA\OrbShatter.ini, created on first start: Enabled, AttackContainers, AttackNonContainerDestructibles.
- Save-safe: no data written to saves.
